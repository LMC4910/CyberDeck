CyberDeck Designer · UX Architecture · Phase 1 of 4

App Surfaces → IDE Integration Matrix

Complete inventory of all 18 App Surfaces and the 6 existing Designer workspaces, with a binding decision for where every surface lives in the unified application. Nothing remains a standalone page: each surface becomes a workspace, a dockable panel, a floating window, a modal, a global service, or a framework pattern. This document is the contract for Phases 2–4.

01TARGET SHELL · ONE RAIL, SEVEN WORKSPACES

The unified workspace rail

The existing rail (Design · Flows · Library · Vars · Runtime · Preview) absorbs every screen-sized App Surface. Preview and Device Manager merge into one Devices workspace; Welcome and Project Manager merge into one Projects workspace; Themes, Assets and the component gallery become tabs of Library. Everything else is chrome shared by all workspaces — one title bar, one status bar, one inspector, one dock system.

03SURFACE INVENTORY · PURPOSE & DEPENDENCIES

Every surface, analyzed

Entry and exit points assume the unified shell — no surface ever leaves the main window except the two floating windows, and even those share theme, typography and the command palette.

SplashSVC

Engine + plugin host boot progress. Becomes a 1–2s overlay, never a "screen".

EntryApp launch onlyExitAuto → last session or ProjectsNeedsEngine status, plugin host
WelcomeWS

Re-entry hub: continue session, pinned/recent projects, templates. Becomes the Home view of Projects.

EntryBoot with no project · ⌘1ExitOpen project → DesignNeedsProject index, device/flow counts, templates
New Project WizardMODAL

4 steps: template, details, features, summary. Stays a wizard — the only true modal flow.

Entry⌘N · Projects toolbar · paletteExitCreate → Design · CancelNeedsTemplates, folders, devices, themes, plugins
Project ManagerWS

Full library: folders, cloud, shared, archive, per-project inspector. Merges with Welcome into one workspace with two views.

Entry⌘1 · breadcrumb · paletteExitOpen → Design · stays residentNeedsProject files, sync state, version index
SettingsWIN

20 panes of app-level defaults. Device/plugin instance config moves out to workspace inspectors; panes deep-link both ways.

Entry⌘, · gear · deep linksExitClose window · changes apply liveNeedsPrefs store, theme list, keymap profiles
Theme ManagerWS

Token editor with live preview + marketplace. Becomes Theme Studio in Library; activating a theme restyles the entire IDE instantly.

Asset ManagerWS

Grid, collections, smart folders, per-asset references and optimization. Full view in Library; slim strip docks at the bottom of Design for drag-to-canvas.

EntryLibrary › Assets · file drop anywhereExitDrag to canvas · close tabNeedsAsset index, usage refs, optimizer
Device ManagerWS

Pairing, calibration, profiles, connection log. Merges with Preview: one Devices workspace — cards on the left, live mockups in the stage.

Per-integration overview, variables, events→flows, permissions, logs. Becomes Integration Center: a stage tab + status-bar health dots.

Timeline, named snapshots, visual diff, conflict resolution. Right-dock Timeline panel available in every workspace; compare opens in the stage.

Search, rebind, conflicts, profiles, key map. Becomes the Keyboard pane of Preferences — every palette command exposes "Edit shortcut".

Entry⌘K ⌘S · Preferences · paletteExitSave profile · closeNeedsCommand registry (single source)
About & DiagnosticsFW

Splits: version/license/credits → Preferences › About; live CPU/GPU/log feed → Diagnostics panel docked in Runtime.

EntryPreferences · Runtime · paletteExitCopy diagnostics · report bugNeedsEngine telemetry, system info, plugin versions
Onboarding TourSVC

9-step spotlight tour + 7-item checklist. Runs over the real IDE, not a mock — checklist pins as a floating card until dismissed.

EntryFirst launch · Help · paletteExitFinish/skip · resume any timeNeedsAnchor registry for spotlights
Notification CenterPANEL

Filtered inbox with inline actions (retry flow, re-auth, install update). Becomes a right drawer from the bell + toast layer; count in title bar.

EntryBell · ⌘⇧N · toast clickExitInline action → owning workspaceNeedsEvent bus, per-source routing prefs
Empty StatesFW

12 patterns (no projects, offline, device dropped…). Not a screen — each pattern is owned and rendered by its host panel.

EntryIn-place, automaticExitCTA → relevant actionNeedsPattern components in design system

Rename, destructive delete with reference warnings, unsaved changes, auth, sync conflict, crash recovery, export. One global framework, one API.

EntryInvoked by any workspaceExitConfirm/cancel · esc/↵NeedsFocus trap, reference counts, kbd map

8 menu types → one Interaction Framework. Items pull from the same command registry as the palette, so shortcuts always match.
