# Project instructions

- Do NOT create a new design file for each request. Update the existing current design file in place (currently `CyberDeck IDE (Phase 4).dc.html`) so the design stays consistent.
- Only fork a new file if the user explicitly asks for a new version or a divergent exploration.
- Follow the established visual vocabulary: dark cyber theme, existing CSS variables (--accent, --ink, --line, etc.), Rajdhani/mono type, existing panel/tab/row patterns.
- `ROADMAP.md` holds the full phased build plan and current status. When the user says "continue", read ROADMAP.md, resume at the first phase not marked ✅, and update its status when done.
