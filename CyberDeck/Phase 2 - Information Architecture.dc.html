Information Architecture — The Unified Shell

One window, seven workspaces, four dock zones, one command registry. This blueprint defines the shell every surface from the Phase 1 matrix plugs into: the persistent chrome, where panels may dock, how navigation works, and the registry that makes every feature searchable and executable from anywhere.

01SHELL ANATOMY · 8 ZONES

Everything shares this frame

Zones 1, 2 and 7 are permanent chrome — identical in every workspace. Zones 3, 5 and 6 are dock zones (dashed green): any dockable panel can live in any of them, float, or collapse. Zone 4 is the stage each workspace owns. Zone 8 (pink) is the overlay layer for global services.

4
Center stage — tabbed documents

Each workspace owns its stage (canvas, node graph, table, device mockups). Stage tabs behave like editor tabs: pin, split right, reorder, close others. Theme Studio and Integration Center open here as tabs.

5
Right dock — context panels

The shared Inspector (one component, many schemas), the Timeline panel and the pinned Notification drawer. Inspector always reflects the global selection, whatever workspace produced it.

6
Bottom dock — horizontal panels

Asset strip in Design, execution log + Diagnostics in Runtime, connection log in Devices. Panels here support multi-tab and drag out to float.

7
Status bar — live truth

Engine state, live device count, plugin health dots, active theme pill, save/sync pill, cursor and grid state. Every item click-navigates to its owner; right-click customizes visibility.

8
Overlay layer — global services

Command palette, universal search, Dialog Framework, notification toasts, onboarding spotlight, context menus. Strict z-order: menus > dialogs > palette > drawer > toasts > tour.

05EVENT BUS · EVERYTHING TALKS TO EVERYTHING

Selection is global state

06LAYOUT PERSISTENCE · PRESETS

Layouts are data

Session restore

Dock sizes, open stage tabs, panel visibility and the active workspace persist per project and restore on open.

Workspace presets

Named layouts — "Streaming", "Debugging", "Minimal" — snapshot all dock state. Switchable from the palette or status bar.

Detach & multi-monitor

Any dock panel detaches into an OS window and rejoins by drag. Floating windows remember their display.
